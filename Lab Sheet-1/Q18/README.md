# LABSHEET-1 - Q18

## Question

Create a Departments collection.

## Aim

To create a new collection named `Departments`.

## MongoDB Commands

```javascript
db.createCollection("Departments")

show collections
```

## Explanation

The `createCollection()` method is used to create a new collection in the current database.

The collection created in this practical is named `Departments`.

The `show collections` command displays the collections available in the database.

## Technology Used

- MongoDB
- MongoDB Shell (mongosh)

## Result

The `Departments` collection was successfully created.
