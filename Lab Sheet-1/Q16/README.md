# LABSHEET-1 - Q16

## Question

Count the total number of student documents.

## Aim

To count the total number of documents in the `Student` collection.

## MongoDB Commands

```javascript
db.Student.countDocuments()

db.Student.find().pretty()
```

## Explanation

The `countDocuments()` method counts the total number of documents in the `Student` collection.

The `find()` command is used to display the student documents.

## Technology Used

- MongoDB
- MongoDB Shell (mongosh)

## Result

The total number of student documents was successfully counted.
