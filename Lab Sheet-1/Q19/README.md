# LABSHEET-1 - Q19

## Question

Drop the Departments collection.

## Aim

To remove the `Departments` collection from the database.

## MongoDB Commands

```javascript
db.Departments.drop()

show collections
```

## Explanation

The `drop()` method is used to permanently remove the specified collection from the database.

The `Departments` collection is removed using the `drop()` method.

The `show collections` command is used to display the remaining collections.

## Technology Used

- MongoDB
- MongoDB Shell (mongosh)

## Result

The `Departments` collection was successfully dropped.
