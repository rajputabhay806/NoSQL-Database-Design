LAB SHEET 5 solutions (Q1-Q15), based on uploaded PDF.
Q1-Q10: Riak KV examples using curl/HTTP API or Python.
Q11-Q14: Neo4j Cypher scripts.
Q15: Python Neo4j driver CRUD and relationship query.

Riak examples assume HTTP API at http://localhost:8098 and an enabled default bucket type.
Run .sh files in Linux terminal with curl; run .cypher files in Neo4j Browser/cypher-shell.
Q15.py requires: pip install neo4j; set NEO4J_URI, NEO4J_USERNAME, NEO4J_PASSWORD.
These are educational examples, not tested against a live database. Riak Data Type endpoints and quorum options can vary by release.
